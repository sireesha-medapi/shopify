# Shopify-Style Product Page

## Features

- Scrollable product image gallery with zoom on hover
- Product variants (color + size) with localStorage persistence
- Modal-based size chart (accessible: ESC key, overlay click, close button)
- Clickable star rating system (stored in localStorage)
- Product info tabs (Description, Info, Shipping)
- Fully responsive: mobile, tablet, desktop
- Smooth transitions and micro-interactions
